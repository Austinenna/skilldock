# SkillDock v0.1.0

第一个可打包的 macOS release candidate。

## 亮点

- Tauri macOS app bundle，带原生窗口与应用图标资源。
- DMG 安装镜像，包含拖到 Applications 的安装入口。
- 发布脚本串起 app 签名、DMG 签名、checksum 生成和可选 notarization。

## 产物

- `SkillDock.app`
- `SkillDock_0.1.0_aarch64.dmg`
- `SkillDock_0.1.0_aarch64.dmg.sha256`

## 签名

当前机器钥匙串里没有有效的 Developer ID Application 身份，因此本地产物使用 ad-hoc 签名。公开分发前，先安装 Developer ID Application 证书，然后运行：

```bash
SKILLDOCK_SIGNING_IDENTITY="Developer ID Application: Your Name (TEAMID)" \
SKILLDOCK_NOTARY_PROFILE="skilldock-notary" \
pnpm release:mac
```

脚本会为 `.app` 和 `.dmg` 做带时间戳的签名，把 DMG 提交给 Apple notarization，staple 公证票据，并验证最终镜像。
