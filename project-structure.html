项目总览

SkillDock 是一个桌面端 Skill 管理器。前端负责三栏界面、列表、详情、设置和导入弹窗；后端通过 Tauri command 操作本地文件系统，把真实 skill 放在 ~/.skilldock/skills/，再用 symlink 路由到 Claude、Codex、Cursor 等平台目录。

前端源码 后端源码 配置与构建 资源与图标 生成/依赖产物
1
React UI 发起操作用户点击扫描、导入、删除或平台开关，前端从 src/ipc.ts 调用 Tauri invoke()。
2
Tauri 后端执行命令main.rs 注册命令，Rust 模块分别处理平台定义、skill 扫描、symlink 路由和配置读写。
3
文件系统作为事实来源后端读取 ~/.skilldock/skills/ 和各平台 skills 目录，返回 skill 列表、路由状态和冲突信息。

后端重点

后端没有 HTTP 路由或数据库，主要是本地文件系统服务。它把 Tauri command 暴露给前端，负责扫描 central skills、创建/删除 symlink、保护真实目录不被误删，并把用户偏好保存到应用数据目录。

当前已实现的是 v1 MVP：平台列表、skill 扫描、导入、删除、路由开关、配置持久化。开发文档中提到的 AI 摘要、文件监听、SQLite 缓存、Keychain API key 暂未落地到当前代码。

命令列表

list_platforms()

返回后端硬编码的平台清单。

scan_skills()

确保 central 目录存在，扫描 skill 目录并计算大小、文件数、更新时间、路由状态和冲突。

import_skill(name, tagline)

创建新的 central skill 目录并写入基础 SKILL.md 模板。

delete_skill(id)

删除 central 中的真实 skill 目录，并清理所有指向它的平台 symlink。

add_route(skill_id, platform_id)

为目标平台创建指向 central skill 的 symlink。

remove_route(skill_id, platform_id)

只移除确认指向 central skill 的 symlink，拒绝删除真实文件或指向别处的链接。

get_config()

读取用户偏好；缺失或损坏时回退默认配置。

update_config(patch)

浅合并配置 patch，写回 config.json 并返回新配置。

前端重点

前端是一个 Vite + React + TypeScript 单页应用。App.tsx 包含主要 UI 组件：侧栏、列表/网格、详情面板、平台路由开关、设置面板和导入弹窗。ipc.ts 是前后端边界，所有真实 IO 都交给 Rust。

src/main.tsx

创建 React root，并在 #root 上渲染 App。

src/App.tsx

应用主界面和状态中心；加载平台、配置、skill 列表，处理搜索、切换视图、增删 skill 和路由开关。

src/ipc.ts

把 Tauri invoke() 封装为 api 对象，前端其他代码只调用语义化方法。

src/types.ts

定义 Platform、Skill、Config 等共享类型，和 Rust 返回结构的 camelCase JSON 对齐。

src/palettes.ts

定义 cool、warm、slate 三套主题色，以及设置界面使用的色块选项。

Tauri v2 权限配置，允许主窗口使用默认核心能力和窗口拖拽能力。

src-tauri/src/main.rs

Rust 后端入口：声明模块并注册所有可被前端调用的 Tauri command。

src-tauri/src/platforms.rs

平台注册表：定义 central、Claude、Codex、OpenClaw、Cursor 等平台的 id、名称、目录路径、分组和 hub 标记。

src-tauri/src/skills.rs

skill 管理核心：扫描 central 目录、解析 SKILL.md 描述、统计大小和文件数、计算路由状态、导入和删除 skill。

src-tauri/src/routes.rs

路由管理：添加平台 symlink、删除平台 symlink，并处理冲突和安全检查。

src-tauri/src/config.rs

配置存储：读取和更新用户偏好，保存到 Tauri app data 目录下的 config.json。

src-tauri/src/error.rs

统一错误模型：把 IO、JSON、非法名称、找不到平台/skill、冲突等错误序列化给前端。
